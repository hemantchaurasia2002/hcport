# Hemant Chaurasia — portfolio

Cinematic personal site for Hemant Chaurasia. Next.js, React, TypeScript, and SCSS. Motion uses GSAP, Lenis, Motion, Anime.js, and a single React Three Fiber scene.

```bash
npm install
npm run dev
```

Set `NEXT_PUBLIC_SITE_URL` to the real domain before a production deploy. Canonical URLs and `sitemap.xml` use that value. No domain was invented in the repository.

The resume download is `public/Hemant-Chaurasia-Resume.pdf` (the September 2026 resume). The YouTube channel URL was not available and is not linked.
